# Criminal Activity and Object Detection System

## Overview
The Criminal Activity and Object Detection System is a web-based interface developed for monitoring and displaying real-time detection results generated by an AI-powered detection model. The system provides users with an interactive and responsive dashboard to visualize detected criminal activities and objects efficiently.

## Features
- Real-time detection result display
- API integration for dynamic data updates
- Responsive and user-friendly interface
- Interactive monitoring dashboard
- Optimized frontend performance and usability

## Technologies Used
